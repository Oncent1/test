# Quantum City Game Prototype

This repository contains a minimal Panda3D prototype demonstrating a futuristic city environment. The player can move smoothly, toggle between first- and third-person camera modes, and "quantum leap" to random locations in the scene.

## Requirements

- Python 3.11+
- [Panda3D](https://www.panda3d.org/) engine

Install Panda3D via pip:

```bash
pip install panda3d
```

## Running the Game

Execute the main script:

```bash
python main.py
```

### Controls

- **W A S D**: Move the player
- **Arrow keys**: Rotate left or right
- **C**: Toggle first/third person camera
- **Q**: Quantum leap (teleport to a random location)
- **Esc**: Quit

The environment is procedurally generated with simple boxes representing buildings to create a basic futuristic city feel.
